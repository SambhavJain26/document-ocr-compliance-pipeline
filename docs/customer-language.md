# Customer Language — US Residential Property Management

Created: 2026-08-01

Vocabulary reference for writing to property managers. Fills the Customer Language gap that every draft otherwise fills with my approximation of how this industry talks.

## Terminology

| Term | Usage |
|---|---|
| **COI** | The standard abbreviation, used unglossed in job listings and industry writing. Safe to use without expanding it — expanding it on a post aimed at property managers reads as talking down |
| **doors** | The unit of scale. "5 to 500+ doors," "a 300-door portfolio." Never "units" when describing company size |
| **vendor compliance** | The umbrella term for this whole area of work |
| **vendor credentialing** | Used interchangeably, slightly more formal, favored by the larger platforms |
| **ownership groups** | Portfolios managed for multiple owners, where requirements differ per owner |
| **lapse** | What a certificate does when it expires. "Lapsed coverage," "gaps" |
| **coverage limits** | Property-specific minimums |
| **the file** | Where documents live, conceptually. "In the file," "on file" |

**The document bundle.** COIs never travel alone in this industry's mental model. They come grouped with W-9s, state trade licenses, trade certifications, and signed contracts. Any post that treats the certificate as an isolated artifact will read as narrow to someone who deals with the whole stack.

**Who actually does this work.** Not the property manager. Compliance handling "typically falls on office administrative teams." This matters for the copy: the person feeling the pain and the person buying are often different people. Write about the work, not about the reader's own hands.

## Pain phrasing worth borrowing

Phrases that recur across sources, in roughly the industry's own words:

- Certificates "expire quietly because no one set up expiration tracking"
- Teams get "buried in spreadsheets, emails, and follow-up work"
- "Manual tracking, repeated follow ups, rework, and approval delays"
- "Spreadsheets, shared drives, and email requests" — the actual tooling
- "Renewals stalling"
- "Coverage gaps still slip through"

**Two findings that matter more than the phrasing:**

**Property managers are not trained in insurance.** Sources note they "aren't given specialized training in insurance compliance," so they're often unsure whether a certificate actually meets requirements. This validates the honesty positioning — a post explaining what a certificate does and does not prove is genuinely useful, not condescending.

**Vendors resent the process.** A recurring complaint is that vendors get "discouraged by a cumbersome compliance process," navigating "a confusing portal" and being asked repeatedly, which "sours the working relationship." The relationship cost is a real, felt problem and nobody in the category is addressing it.

## The competitive landscape — the significant find

This is not an empty space. There is an established category of COI-tracking software selling to exactly this ICP:

**myCOI · NetVendor · VendorAccess · BCS · SmartCompliance · ExpiryEdge · Jones · Vertikal RMS · Lula**

Most of the search results for vendor insurance tracking are these companies' marketing, which means property managers researching this problem are already being sold to heavily.

**Why this sharpens the positioning rather than threatening it.** Every one of these is a SaaS product with a portal. The category's own documented failure mode is the portal itself — vendors find it cumbersome, get discouraged, and the relationship suffers. The offer is the direct answer to that: automation inside the systems that already exist, using the mailbox the vendor already emails, with no portal for anyone to log into.

**Copy implications:**

- Do not describe the problem as though nobody has noticed it. They have, and there are nine companies selling to it.
- The differentiator is not "I solve COI tracking." It is "I solve it without adding a system anyone has to adopt."
- Avoid the category's vocabulary where it has been worn out by marketing: "streamline," "centralize," "end-to-end," "seamless," "compliance made easy."
- The word **compliant** is already banned for honesty reasons. It is also the category's most overused word, which makes avoiding it a positioning advantage as well as an accuracy one.

## A cadence discrepancy worth knowing

The industry-standard reminder pattern quoted repeatedly is **60, 30, and 7 days** before expiration.

The built system uses **60, 30, 14, and 0**.

Not wrong, but different from what a property manager expects. If any post discusses reminder timing, either match the convention or say plainly why the schedule differs. Silently using non-standard numbers reads as not knowing the norm.

---

## Rules for the copy

1. Use **COI** unexpanded. Use **doors** for scale. Use **lapse** for expiry.
2. Never write **units** when describing portfolio size.
3. Treat the certificate as part of a document stack, not an isolated thing.
4. Write about the work, not the reader's hands — the person doing it may be an admin, not the buyer.
5. Avoid worn category vocabulary: streamline, centralize, seamless, end-to-end, compliance made easy.
6. Do not claim the problem is unrecognized. Claim the approach is different.
7. Flag any phrase that is my invention rather than sourced, so it can be replaced after real group research.
