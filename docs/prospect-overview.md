# Vendor Certificate Chasing System

Property managers already have enough systems. This one is narrow on purpose.

It tracks vendor certificate paperwork, reads the important date facts, shows the source document, and helps your team chase renewals before the paperwork goes stale.

That is the job.

## The Problem It Solves

Every property management office has a version of this process.

A plumber sends a certificate PDF. An insurance agent forwards a renewal. A landscaper says the new certificate is coming. Someone in the office opens the file, reads the dates, and types the details into a spreadsheet, a vendor profile, or a note inside the property management system.

Then the office gets busy.

The certificate might be filed but never entered. The date might be entered once and forgotten. The agent's email might sit in the inbox. A vendor might renew with a new carrier and nobody updates the record.

None of this feels urgent until someone asks a simple question:

> "Which vendors have current certificate paperwork on file today?"

That question should not take an afternoon to answer.

## What The System Does

The system gives you one place to see vendor certificate paperwork status by date.

It can:

- receive certificate PDFs by email or upload
- read vendor, carrier, policy number, limit, and expiration facts
- store the original source document
- show every vendor in one dashboard
- flag missing, expired, expiring, or review-needed paperwork
- draft short renewal request emails
- wait for a human before sending any chase email
- keep a record of reminders sent and follow-up dates

It is built for the work that usually lives in a spreadsheet, inbox, calendar reminder, or someone's memory.

## How It Fits Into Your Office

The office process is simple.

1. Your vendor list is loaded first.
2. Certificates arrive by email or upload.
3. The system reads the document facts.
4. The dashboard updates.
5. Anything unclear goes to review.
6. When a renewal needs chasing, the system drafts the reminder.
7. A manager reviews the draft.
8. The email goes out only after that review.

No one needs to retype every date by hand. No one needs to remember which vendor renews next month. The paperwork facts stay visible.

## What The Dashboard Shows

The dashboard is the main screen your team uses.

Each row shows:

- vendor name
- trade
- carrier
- policy number
- general liability limit
- expiration date
- current paperwork status by date
- source document link

The status wording stays plain:

- `Current until <date>`
- `Expires in <n> days`
- `Expired <n> days ago`
- `No certificate on file`
- `Needs review`

The source PDF is always nearby. If a manager wants to check the policy number, carrier name, or date, they can open the original document.

## What Happens When A Certificate Arrives

Here is a normal day in the office.

A vendor or insurance agent emails a certificate PDF.

The system reads the certificate and pulls out the useful facts: vendor name, carrier, policy number, general liability limit, and expiration dates. It also keeps the PDF so your team can open the source document later.

If the document is clean, the dashboard row updates.

If the document has a problem, the row goes to review. That can happen when the dates look wrong, the holder name is off, the PDF is password-protected, the vendor name is close but not exact, or the certificate is not really a certificate.

The system does not guess. It asks for a human.

## What Happens Before Renewal

When a certificate is missing, expired, or close to expiration, the system prepares a chase email.

The draft is short and factual. It names the vendor, references the certificate issue, and asks for updated paperwork.

Then it stops.

A manager gets an email with the draft and chooses whether to send it. That review step matters. The system is not sending vendor emails on its own.

After the manager approves the email draft, the message goes out from the configured mailbox and the system records the send time, recipient, and follow-up date.

## Why This Is Useful

The value is not that it adds another dashboard.

The value is that it removes small manual steps that repeat all year:

- opening PDFs
- reading date fields
- typing policy facts
- checking which vendors are missing paperwork
- writing the same renewal request again
- remembering who ignored the first message
- finding the source document later

For a small or mid-sized property management company, that work is easy to postpone. It is also easy to lose.

This system keeps it in view.

## What It Does Not Do

This is important.

The system tracks certificate paperwork. It does not verify coverage.

It does not:

- confirm that a policy is active with the carrier
- confirm additional insured status
- interpret endorsements
- detect forged certificates
- detect mid-term cancellation
- decide whether a vendor can work on a property
- replace your insurance broker, attorney, or risk manager
- update your property management software

A certificate is a paperwork record. It is not the policy itself. If you need policy-status confirmation or endorsement review, that still belongs with the agent, carrier, broker, or legal advisor.

## What You Need To Start

Setup starts with a few practical items:

- your vendor list
- each vendor's trade
- vendor or producer email addresses when available
- the legal names that should appear as certificate holder
- your general insurance requirements by trade
- the mailbox that receives certificates
- the person who should review chase emails

From there, existing certificates can be processed in a batch. The first useful output is the dashboard: current by date, expired by date, missing paperwork, and review rows.

## What The First Week Looks Like

The first week is usually straightforward.

Day one: load the vendor list and confirm the holder names.

Day two: connect the mailbox and process existing certificate PDFs.

Day three: review the dashboard together and clean up vendor name issues, holder notes, and review rows.

After that, the system watches the dates and drafts renewal requests when paperwork needs attention.

## The Best First Test

The easiest way to see whether this is useful is to send ten vendor certificates.

No property management system access. No vendor portal. No large project.

Send ten PDFs and review the result:

- which vendors have certificate paperwork on file
- which dates are coming up
- which documents are already past the printed date
- which rows need review
- which source PDFs support the dashboard facts

That is enough to know whether the process belongs in your office.
